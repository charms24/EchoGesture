# EchoGesture

Private collaboration repo for the EchoGesture WLASL project.

Download `EchoGesture_collaboration_bundle.zip` and extract it to get the complete project directory, including the training and inference code, results, WLASL metadata, and trained model artifacts.

The 5 GB WLASL video download and local virtual environments are intentionally excluded. The current model and vocabulary are based on the 100-class WLASL subset.
